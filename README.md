### 1. Retail Transaction Dashboard
## 📌 Description
Dashboard interaktif ini menyajikan analisis komprehensif terkait tren penjualan dan kinerja transaksi ritel. Proyek ini memvisualisasikan data pendapatan, keuntungan, penggunaan metode pembayaran, serta performa kategori produk dan pelanggan utama untuk mendukung pengambilan keputusan berbasis data.
## 📊 Key Highlights
- **Financial Overview:** Total Revenue ($8.57bn), Profit ($2.01bn), Discount Amount ($33.83m), dan Quantity Sold (13.6k).
- **Sales & Payment Trends:** Analisis tren penjualan bulanan dan preferensi metode pembayaran pelanggan (seperti Cash on Delivery, Payaxis, Easypay).
- **Category & Product Performance:** Perbandingan volume transaksi dan pendapatan berdasarkan kategori produk (Mobiles & Tablets, Entertainment, Computing, dll.).
- **Customer & Product Summaries:** Identifikasi produk terlaris (*Top SKUs*) dan profil pelanggan berpendapatan tertinggi (*Top Customers*).
## 🛠️ Tools Used
- Google Sheets
- Dashboard & Data Visualization (Looker Studio)

### 2. Credit Card Customer Analytics Dashboard
## 📌 Description
Proyek analisis data ini berfokus pada evaluasi demografi, tingkat risiko, dan performa keuangan pemegang kartu kredit. Dashboard ini membantu memahami karakteristik nasabah, distribusi pendapatan bunga, serta faktor risiko penunggakan (*delinquent accounts*).
## 📊 Key Highlights
- **Key Metrics:** Total Customer Count (5,054), Total Transaction Volume (326,544), Total Transaction Amount ($22.31M), dan Average Satisfaction Score (2.25).
- **Demographic Analysis:** Pemetaan profil nasabah berdasarkan usia, tingkat pendidikan, status pernikahan, jenis pekerjaan, dan lokasi (*State*).
- **Revenue & Expense Breakdown:** Analisis pola pengeluaran nasabah (Bills, Entertainment, Fuel, Grocery) serta pendapatan bunga (*interest earned*) per segmen pekerjaan.
- **Risk Profile:** Evaluasi akun menunggak (*delinquent accounts*) berdasarkan demografi dan tingkat pendidikan untuk manajemen risiko.
## 🛠️ Tools Used
- Google Sheets
- Dashboard & Data Visualization (Looker Studio)

### 3. Human Capital Analytics Dashboard
## 📌 Description
Proyek visualisasi dashboard interaktif yang menyajikan ringkasan eksekutif mengenai metrik utama Human Capital. Dashboard ini dirancang untuk membantu tim HR dan manajemen memantau distribusi karyawan, tingkat efektivitas rekrutmen, serta dinamika promosi secara visual.
## 📊 Key Highlights
- **Executive Overview Dashboard:** Tampilan visual tingkat promosi karyawan secara keseluruhan (8.5% dipromosikan vs 91.5% tidak dipromosikan).
- **Department Distribution:** Visualisasi sebaran total jumlah karyawan di seluruh unit kerja (seperti Sales & Marketing, Operations, Technology).
- **Recruitment Channel Comparison:** Perbandingan efektivitas jumlah rekrutmen dan rasio kelolosan promosi antar saluran rekrutmen.
- **Interactive Filters:** Penapisan data berdasarkan Departemen, Jenis Kelamin, dan Status Promosi untuk analisis mendalam.
## 🛠️ Tools Used
- Google Sheets
- Dashboard & Data Visualization (Looker Studio)
